# 3.4.3-oss.1

2026-11-09。

## 重新监控

- 重置前通过独立公共 HTTP 池并行读取最新区块头，检查区块号和时间戳，拒绝无效或过期结果；必要时使用当前代际的公共 WebSocket 只读兜底。
- 无法确认新鲜区块头时不清除数据，不借用交易 RPC 的配额。
- 新增需要控制请求鉴权的只读 `GET /api/reset-preview`；仅验证取头路径，不触发重置、钱包操作或窗口跳转。
- 用户明确重置成功后唤醒补扫，避免继续等待旧的错误退避。系统不会自动跳过历史缺口。

## 监控健康

- 网页同时显示订阅、区块头、完整补扫边界、区块缺口、最后成功时间及错误退避。
- WebSocket 已连接不再单独代表监控正常。补扫未验证、停滞或明显落后时显示异常。
- 健康判断使用服务端时间，减少笔记本时钟偏差造成的误判。
- 补扫错误采用有上限的指数退避；历史追赶成功时也限制请求节奏。

## B 币周期

- 每个 600 秒周期必须有达到 $10,000 的有效市值记录；市值未知不会无限保留。
- 周期通过后，新周期峰值从 0 开始，不沿用旧报价。长时间断线不能凭旧值连续通过多个周期。
- 到期后的新行情不能补救已失败的上一周期。普通 B、复活 B、候补及在窗口中的 B 使用同一规则。
- C 的 240 秒观察、一次复活限制、人工删除和终态规则保持不变。

## 源码副本

- 保留本地监控名单配置、默认回环监听、便携资源路径及默认关闭交易的设置。
- 不包含运行数据库、钱包、RPC 密钥、控制口令、浏览器资料、日志或个人监控名单。
- 新增健康状态离线测试，并纳入 JavaScript 测试入口。Rust 测试覆盖独立取头、退避、重置唤醒、未知市值淘汰及周期峰值隔离。

离线测试不保证外部节点永久可用，也不构成主网交易验证。
